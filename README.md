# Student_Exam_Analysis_Arumugam

Project Description

The Student Exam Performance Analysis project focuses on analyzing students' academic performance and understanding how lifestyle and well-being factors influence exam scores. Using a dataset containing 100,000 student records and 44 features, this project explores the relationship between academic results, sleep hours, stress levels, motivation, screen time, physical activity, and exam anxiety.

The project uses data cleaning, exploratory data analysis (EDA), and interactive Power BI dashboards to identify performance trends, analyze pass and fail rates, and uncover factors associated with students' academic success.
